# CHEF TTK PRO — новое Flutter-приложение

Отдельный проект **CHEF TTK PRO** на ветке `chef-ttk-pro-flutter`. Не является FARUKH AI Premium или старым FARUKH TTK PRO.

## Как получить APK

Откройте GitHub Actions → **CHEF TTK PRO — Flutter Android APK** → последний успешный запуск → Artifacts → `CHEF-TTK-PRO-v0.5-debug-APK`.

Эта ветка сначала содержит архив оригинальных исходников v0.5 в пяти проверяемых частях (SHA-256 исходного tar.xz: `85240b3ef886ff56c513711c9552a5d47f31b79d7cfe4a747e4fdbd14181dad6`). Workflow проверяет контрольную сумму, распаковывает исходники, запускает Flutter analyze/test, создаёт отладочный APK и выкладывает его как artifact. После успешной сборки workflow публикует распакованные файлы кода в эту же ветку.

**Debug APK не является подписанным release.** Чтобы выпускать обновления без удаления приложения, требуется постоянный приватный релизный сертификат и реальная проверка на Android.

Согласованный дизайн документа: одна страница А4, изумрудно-золотые таблицы, без FARUKH AI Premium и лишних верхних кнопок.
