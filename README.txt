FARRUKH AI MOBILE — PWA

Это мобильная версия, которую можно установить на Android как приложение.

ЧТО ЕСТЬ
- мобильный интерфейс
- AI-чат
- голосовой ввод
- озвучка ответов
- задачи
- проекты
- калькулятор себестоимости / Food Cost
- установка на главный экран
- офлайн-кэш интерфейса

КАК ЗАПУСТИТЬ ЛОКАЛЬНО НА КОМПЬЮТЕРЕ
1. Установить Node.js LTS
2. npm install
3. Скопировать .env.example в .env
4. Добавить OPENAI_API_KEY (необязательно для локального режима)
5. npm start
6. Открыть http://localhost:3000

КАК ПОЛУЧИТЬ НА ТЕЛЕФОНЕ КАК ПРИЛОЖЕНИЕ
Приложение нужно разместить на HTTPS-хостинге (например, Render, Railway, Fly.io, VPS или другом Node.js-хостинге).
После размещения:
1. открыть ссылку в Chrome на Android;
2. нажать меню ⋮;
3. «Добавить на главный экран» / «Установить приложение».

После этого FARRUKH AI будет запускаться с иконки почти как обычное Android-приложение.

ВАЖНО
- API-ключ должен храниться только на сервере в переменной окружения OPENAI_API_KEY.
- Не вставлять API-ключ в app.js.
- Для настоящей синхронизации телефона и компьютера следующим шагом нужна общая облачная база данных.
