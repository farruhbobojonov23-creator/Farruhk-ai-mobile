# OCEAN ULTRA · аудит Xiaomi 15T — версия 4.0.2

Основание: пять последних изображений пользователя (включая увеличенный фрагмент полосы волн и скриншоты Каталог/ТТК/рабочая студия). Дата: 22.11.2026.

| Видимая проблема | Причина, выявленная в коде | Исправление |
|---|---|---|
| Прямая бирюзовая линия над волнами | `o40_waves.webp` содержит фрагмент светящейся рамки другого блока на верхнем крае; изображение показывалось целиком | CSS background-size 145%, выравнивание по нижнему краю + мягкая маска верхней границы, в главной и внутренних вкладках |
| Полупрозрачный текст «Создавай идеальные ТТК» позади заголовка «Каталог» и «ТТК» | В `ocean-4-exact.css` фон внутренней шапки использовал `o40_hero.webp` с уже нарисованными надписями | Поменян фон на `ocean_hero_whale.webp` — изображение кита без надписей; поверх размещён настоящий HTML-заголовок |
| Дублирующиеся надписи на баннере рабочего кабинета | В `ocean-4-workspace.css` также использован `o40_hero.webp` с вшитыми словами | Тот же фон заменён на `ocean_hero_whale.webp` без текста |
| «Создать ТТК» плохо читается на белой кнопке рабочего кабинета | Стиль `.btn-light` противоречил принудительному белому тексту героя | Ярко-розовый 3D CTA и контрастная белая надпись |
| Подписи нижнего меню плохо видны | Темно-синяя/неполная прозрачность текста на тёмно-синем меню | Белые подписи, тени текста, непрозрачные SVG, сохранён красный индикатор активного раздела |
| В разделе ТТК пятая карточка занимает левую половину, оставляя пустую правую | Нечётное число пунктов при 2-колоночной сетке | Последняя карточка занимает ширину обеих колонок и получает горизонтальную композицию |

Изменения ограничены двумя последними CSS-файлами и манифестом версии. Переписаны только подключения CSS в `mobile.html` и `index.html`. Режим фиксированной главной страницы (`ocean-home-lock.js`) не менялся.

Статические проверки 14/14 пройдены, ссылки на все фоновые ресурсы в репозитории присутствуют. **Проверка на живом Android WebView и сравнение скриншотов после установки пока не проведены.**

8K качество изображений не заявляется; исходники WebP остаются оптимизированными под мобильные устройства. Данные и документы ТТК, Supabase, APK и печатные шаблоны не затрагивались.
