# MORE SUSHI STUDIO PRO — PEARL ROSE ULTRA 8.0

Дата: 23.11.2026. Утверждённый макет: **последняя, четвёртая яркая розово-перламутровая концепция** (с сакурой, рубиновыми кнопками, золотистыми бликами, суши на тарелке). Не путать с 7.0 CHEF SIGNATURE, который пользователь отверг как слишком тёмный.

## Что заменено
- Мобильный HTML полностью заменён на единую реализацию композиции из макета: компактная шапка с логотипом, обложка с суши, статус облака и кнопка обновления, четыре **живых** показателя, заголовок инструментов, большая рубиновая карточка создания ТТК и две малые карточки каталога/PDF, продолжение работы, пять вкладок внизу.
- Одна мобильная тема `pearl-rose.css`, один служебный скрипт `pearl-rose-ui.js`. Ни CHEF SIGNATURE, ни RUBY WHITE, ни OCEAN стили из предыдущих версий в mobile.html **не подключаются**.
- Одна визуальная тема рабочей студии `pearl-rose-workspace.css` вместо `chef-signature-workspace.css`. Остальные CSS студии необходимы для форм, архивных шаблонов и печати, не удалялись.
- Четыре оптимизированных WebP-предмета, извлечённых **из утверждённого изображения** (без текста/кнопок): роллы на блюде, клипборд ТТК, нигири, принтер. Ресурсы суммарно ~188 КБ. Отдельное масштабируемое SVG сакуры.

## Не менялось
- Авторизация, база и проекты, Supabase, маршруты к конструктору ТТК, библиотеке, шаблонам A4/PDF и настройкам.
- Текущие технологические карты, шаблоны печати, расчёты КБЖУ, журнал действий.
- Android APK не переподписан и не пересобран; новая версия относится **только к веб-интерфейсу**.
- Категории каталога и История PDF с пометкой «СКОРО» по-прежнему не объявляются работающими.

## Контроль перед публикацией
- **21/21** проверок исходников (одна активная тема, совпадение версий, 5 вкладок, 7 ID динамических показателей, корректные JS/CSS, реально существующие WebP/SVG, сохранённые маршруты и возможность обновления).
- Отдельный офлайн Chromium-превью с реальными подготовленными ресурсами и DOM на 320×640, 360×740, 393×760, 393×850, 430×930; нет горизонтальной прокрутки, нет перекрытия текста и кнопки на баннере; на четырёх внутренних вкладках проверен переход и отсутствие JS-ошибок.
- При 320×640 **главная допускает вертикальную прокрутку**, чтобы не обрезать кнопку «Все ТТК»; на 360×740 и выше при наличии места главный экран автоматически фиксируется.

## Пределы проверки
- Проверка в изолированном Chromium имитировала навигацию и графику; в тесте не было реального входа Supabase, поэтому нельзя утверждать, что облако и редактор проверены end-to-end.
- Не подтверждено точное pixel-perfect совпадение с макетом на Xiaomi 15T; это визуальная реализация выбранной композиции. Исходные WebP — достаточно качественные для мобильного экрана, но **не изображения с физическим разрешением 8K**.
