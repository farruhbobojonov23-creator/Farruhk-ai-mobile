# MORE SUSHI STUDIO PRO — восстановлен исходный дизайн OCEAN 3.2

Дата: 22.11.2026. Основание: запрос пользователя «верни как было первый раз, такое ощущение как будто там 3 дизайна» после BLACK GOLD 5.1.

## Точное основание восстановления
Оба файла `mobile.html` и `index.html` восстановлены **байт-в-байт из коммита `c5a602eb3c1d` (17:48 UTC, 22.11.2026), за исключением уникального номера сборки в HTML**. Это первый голубой премиальный интерфейс из сегодняшней серии, до добавления фотореалистичного кита OCEAN 3.3 и всех поздних тем.

## Устранена перегруженность оформления
Было в мобильной странице: 14 CSS + 8 внешних JS, одновременно применяли OCEAN 3.2/3.3/3.4/4.0/4.1 и BLACK GOLD 5.0/5.1. Множественные несовместимые перекрытия стилей и конкурирующие механизмы подгонки главного экрана могли давать конфликтующие размеры и лишнюю перерисовку.

Стало: **5 CSS + 4 JS**, в первоначальном наборе OCEAN 3.2. Удалённые подключения не удаляют файлы из репозитория и не затрагивают серверные данные.

В рабочей студии `index.html` теперь 4 исходных CSS вместо 8: убраны OCEAN 4.0/4.1 и BLACK GOLD. Восстановлен оригинальный порядок CSS для форм и рабочих разделов.

## Что не менялось
- Все 5 вкладок; ссылки на конструктор и библиотеку ТТК, PDF и шаблоны A4.
- Данные, авторизация, сохранённые ТТК, проекты и Supabase.
- Способ проверки обновлений интерфейса и Android APK.
- Общие JS-файлы `ocean-updater.js`, `ocean-dashboard.js`, `ocean-refined.js`. Дополнительная строка текущего `ocean-categories.js` синхронизирует атрибут `data-mss-tab` и не изменяет пользовательские данные.

## Проверка
19/19 структурных проверок пройдены: оба файла совпадают с первыми версиями кроме build-строки, все CSS/JS реально существуют, нет загрузки устаревших 4.x/5.x тем, сохранены пять вкладок и все основные рабочие маршруты. UI build: `ocean-3.2.1-original-restored-20261122`.

**Чего это не доказывает**: ускорение именно на конкретном Xiaomi, точное время первого запуска, отсутствие проблем сетевого соединения/Supabase. Потребуется проверка после обновления в Android WebView. Не заявляем «полностью исправлено» без такого теста.
