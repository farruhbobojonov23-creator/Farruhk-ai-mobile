# FARUKH REVISION PRO — Android
Исходники Android APK используют тот же HTML, что и web /revision.html.
В GitHub Actions workflow "Build FARUKH REVISION PRO APK" собирается debug APK.
Debug APK только для испытаний. Для постоянных обновлений потребуется неизменная release-подпись.
Без Frontpad API ввод остатков вручную, хранение в Supabase с RLS после авторизации.
