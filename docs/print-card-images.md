# Изображения карточек FARUKH PRINT

Добавлено 27 сгенерированных предметных изображений встроенным ImageGen. Это иллюстративные фотографии продуктов и инвентаря, а не подтверждение внешнего вида фирменной упаковки или рецептуры.

Готовые JPEG 192×192 встроены в `public/farukh-print/supplemental-photos.js`. Общий объём JPEG: 103 761 байт. Изображения предназначены для карточек; на термоэтикетках не печатаются. Существующие фотографии сохраняются.

## Набор промптов

Общий стиль: photorealistic studio product photography, pure white background, soft shadows, strict 3×3 atlas of equal cells, centered isolated subjects, no text, no logos, no borders.

1. ХАССП: канистра прозрачного рабочего раствора; лоток для замачивания ножей; ёмкость с синей ветошью; дозатор антисептика для рук; распылитель для поверхностей; жидкое мыло; синяя швабра; синее ведро; искусственный веник.
2. Полуфабрикаты A: спайси соус; сырный соус; нейтральное изображение фирменного соуса; такуан; форель; угорь; готовая курица; сурими «Снежный краб»; сливочный соус.
3. Полуфабрикаты B: перец; морковь; соус унаги; соус терияки; сладкий чили; капуста; креветки; огурцы; омлет тамаго.

Атласы разделены по равным ячейкам и уменьшены с помощью Sharp; размеры и объём подобраны под карточки мобильного каталога.
