# Private PP-StructureV3 service
Experimental, not deployed. CPU benchmark used about 7.4 GiB peak RAM. Recommend a machine with 16 GB RAM. A free 512 MB Render service is not suitable. No paid OCR API. Python 3.11. Install requirements, set SUPPLY_OCR_TOKEN to a unique cryptographically random string (32+ characters), start python server.py. Use your own trusted HTTPS reverse proxy with access restricted to authorized users; do not expose Flask directly. The Android WebView sends image only after explicit opt-in. The old native recognition remains available. Photos are removed from service temporary directory; avoid proxy body logging. Endpoint and token are stored on the device; revoke token if device lost. This is not yet validated end-to-end on physical Android. Automated requests currently begin after the first native pass returns. No APK rebuild is included.
