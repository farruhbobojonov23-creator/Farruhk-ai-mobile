# FARRUH WORKSPACE PRO — один Android WebView для всех проектов

Отдельное Android-приложение с уникальным package ID `ai.farukh.workspace`.
Не заменяет установленный FARUKH AI, REVISION или PRINT. Исходные сайты/данные не удаляются.

Веб/PWA не может встраивать сайты с X-Frame-Options/CSP frame-ancestors (например FARRUH AI).
В APK ссылки на ВСЕ семь проектов открываются в ОДНОМ постоянном Android WebView:
все HTTPS-навигации остаются внутри приложения. Верхняя системная панель «‹ Проекты»
всегда возвращает в Workspace; Android «Назад» возвращает к предыдущей странице.

Приложение включает передачу выбора файлов, обычную загрузку HTTPS-файлов, 
Android Print / «Сохранить как PDF», камеру/микрофон по запросу проверенных доменов.
Никакого небезопасного addJavascriptInterface. HTTP заблокирован.

Ограничение: Bluetooth Web API может не поддерживаться Android WebView, проверка
V3 BT на физическом устройстве отдельно. Некоторые сторонние OAuth-провайдеры
не разрешают вход из WebView и могут требовать системный браузер.

Сборка: GitHub Actions → Build FARRUH WORKSPACE PRO Android →
artifact FARRUH-WORKSPACE-PRO-TEST-APK.

Это DEBUG-сборка, а не подписанный постоянным ключом релиз. Чтобы следующие нативные
APK ставились поверх старой версии, нужно хранить один постоянный RELEASE-ключ
защищённо в GitHub Actions Secrets. Не коммитить приватные ключи в репозиторий.
Изменения веб-сайтов внутри этого APK обновляются автоматически без установки APK.
