# FARUKH SUPPLY AI — Android preview

Separate application ID: ai.farukh.supply. Does not replace Farukh Workspace.
No Telegram integration. The current preview stores invoice drafts and originals on this device only. No cloud sync, OCR, automatic updates or production signing yet. Manual confirmation and comparison use the gross line total and user-approved product/group labels. Data can be lost if app is removed. Do not rely on it as the sole copy of invoices. Do not enter real records until storage, authentication, backup and recovery are production-ready.

Build with Android SDK 35, JDK 17 and Gradle 8.10.2: gradle -p supply-android :app:assembleDebug.
