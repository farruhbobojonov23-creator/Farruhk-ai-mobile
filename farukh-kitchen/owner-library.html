Защищённая выдача ТТК

Только подтверждённый владелец может загружать материалы и назначать доступ. Пока оба пакета закрыты для продажи.

ШАГ 1 · ВХОД

Подтвердите почту

Почтовая ссылка должна вести на адрес этого кабинета. Для этого он должен быть указан в настройках Redirect URLs проекта Supabase.

—
ШАГ 2 · ПОДТВЕРЖДЕНИЕ ВЛАДЕЛЬЦА

Защитить право администратора

Откройте закрытый управляющий центр, войдите своим логином и паролем, получите ключ первичной привязки и вставьте его сюда. Ключ не отправляйте в чат.

Эта операция однократная: после первого успешного подтверждения новых администраторов автоматически не создаём.

ШАГ 3 · ЗАГРУЗКА

Четыре коммерческих файла

Выберите четыре локальных файла PDF/ZIP из утверждённого комплекта. Перед загрузкой автоматически сравним размер и SHA-256 с эталоном. Файлы никогда не попадут в публичную папку сайта.

ФайлРазмерХранилищеВыдачаДействие

Кнопка «Разрешить» появляется после проверки загруженного файла. Доступ всё равно получают только подтверждённые покупатели START/PRO.

ШАГ 4 · ДОСТУП ПОКУПАТЕЛЯ

Выдать пакет по email

Покупатель должен сначала войти в свой кабинет по ссылке из письма. Подтвердите оплату вручную до выдачи доступа.

Выдача действует сразу после активации, если нужные файлы уже выпущены. Отзыв закрывает новые скачивания, но не удаляет ранее загруженные файлы у покупателя.
