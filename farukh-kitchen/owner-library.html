ШАГ 2 · ПОДТВЕРЖДЕНИЕ ВЛАДЕЛЬЦА

Защитить право администратора

Откройте закрытый управляющий центр, войдите своим логином и паролем и откройте раздел облачной синхронизации — он может автоматически подтвердить владельца. Затем вернитесь сюда и обновите страницу. Если нужна ручная привязка, откройте в своём браузере выдачу ключа после входа в управляющий центр и вставьте полученный bootstrapToken ниже. Никому не пересылайте ключ.

Эта операция однократная: после первого успешного подтверждения новых администраторов автоматически не создаём.

ШАГ 3 · ЗАГРУЗКА

Четыре коммерческих файла

Выберите четыре локальных файла PDF/ZIP из утверждённого комплекта. Перед загрузкой автоматически сравним размер и SHA-256 с эталоном. Файлы никогда не попадут в публичную папку сайта.

Загрузка всех четырёх файлов одним архивом

Выберите архив «FARUKH_KITCHEN_4_ФАЙЛА_ДЛЯ_ЗАГРУЗКИ.zip», подготовленный для владельца. Мы сверим каждую контрольную сумму перед выгрузкой.

Ниже остаётся возможность загрузки отдельных файлов. После проверки всех 4 файлов доступ автоматически откроется только для покупателей, назначенных владельцем.

ШАГ 4 · ДОСТУП ПОКУПАТЕЛЯ

Выдать пакет по email

Покупатель должен сначала войти в свой кабинет по ссылке из письма. Подтвердите оплату вручную до выдачи доступа.

Выдача действует сразу после активации, если нужные файлы уже выпущены. Отзыв закрывает новые скачивания, но не удаляет ранее загруженные файлы у покупателя.
