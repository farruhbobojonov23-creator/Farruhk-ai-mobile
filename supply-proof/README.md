# FARUKH SUPPLY AI — отдельный проверочный проект

**Статус:** изолированный прототип. **Это не рабочая публикация Android и не замена установленному APK 21.** Действующие приложения, репозиторий основной ветки, учётные записи, платные тарифы и релизы не менялись.

## Запуск (ПК: Windows / Linux / Mac)

Нужны Node.js **20+** и локальная программа Tesseract 5 с языками **rus, eng**. Никаких облачных API, регистрации или оплаты нет.

1. Распаковать ZIP.
2. В папке проекта выполнить `node server.cjs`.
3. Открыть `http://127.0.0.1:8765` на **том же компьютере**.
4. Загрузить одну или несколько фотографий. Если OCR слишком долго работает, его можно обойти: вставить уже распознанный текст и нажать «Разобрать по полям».
5. Исправить поля и отметить ручную сверку перед экспортом JSON или CSV.

Фотографии обрабатываются **только локально**. Они временно записываются в системную папку пользователя для выполнения Tesseract и удаляются при завершении запроса. В публичный GitHub ничего личного не отправляется. Если вы не доверяете компьютеру, не используйте его для конфиденциальных накладных.

Для Windows можно добавить Node.js и Tesseract в PATH; в данном ZIP исходники без установщика. Для Android-фотографий требуется дальнейшая интеграция и отдельное тестирование — существующий APK не менялся.

## Возможности прототипа

- Загрузка изображений в локальный тестовый OCR и ручная вставка OCR-текста.
- Разбор **поставщика «ШАНХАЙ-ТОРГ»** (таблица УПД с кодом единицы 796) по товарной строке, а не по итоговой сумме.
- Получение названий, количества, артикулов, цены с НДС, суммы, фасовки.
- Раздельные единицы сравнения: **₽/кг**, **₽/л**, **₽/шт**; цена упаковки и количество упаковок сохраняются отдельно.
- Редактирование, проверка по исходным фрагментам текста и экспорт CSV/JSON **только после ручного подтверждения**.
- Для остальных поставщиков есть безопасный ручной ввод; **автоматический разбор ещё не реализован**. Никаких угаданных цен.
- Поддержка от 1 до 20 товарных позиций в форме.

## Проведённые проверки

- `node --test tests/*.test.cjs`: **10/10** автоматических синтетических тестов и тестов HTTP.
- Изолированная проверка ранее присланного текста OCR настоящей накладной «ШАНХАЙ-ТОРГ»: **6/6** сопоставлений артикула, количества, цены и суммы, итог **[контрольная сумма закрыта]**. Эти частные данные **не включены в архив**.
- Браузерный тест через Chromium с синтетической накладной: 2 строки, корректный итог 600 ₽, обязательная отметка ручной проверки перед экспортом.
- Браузерный тест с приватным исходным OCR: 6 строк, номер и дата; фотография не проходила в этом тесте через локальный OCR.
- Для остальных шести фотографий: оригиналы найдены приватно, но проверка *фотография → текст → таблица* **пока не пройдена**. Не считать проект готовым.

## Ограничения и безопасность

- Локальная модель распознавания Tesseract на сложных снимках может ошибаться или превышать 55 секунд на страницу; фотографическое распознавание всех семи поставщиков **не подтверждено**.
- Исходный OCR может не содержать часть строк; сервис не должен автоматически подтверждать накладную из-за совпадения одной общей суммы.
- Услуга предназначена для демонстрации проверочного процесса, а не для боевого учёта. Данные не синхронизируются с FARUKH SUPPLY AI.
- При проблеме запрещено публиковать личные оригиналы или их тексты в GitHub Actions.

## Что нужно довести перед боевой интеграцией

1. Приватный объективный фототест всех семи поставщиков, включая все страницы «АЛИДИ ПРОФ».
2. Метрики по каждому полю каждого товара, отдельный учёт реальных документов и синтетики.
3. Проверка работы на новых товарах и на 1–20 строках.
4. Полный цикл Android: выбор фото, OCR, привязка полей, ручная проверка, сохранение.
5. Только после теста — перенос в приложение через отдельный выпуск, без повреждения данных.
